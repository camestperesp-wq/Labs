# Imagenes para el encabezado

Sube aqui las imagenes oficiales con estos nombres:

- `escudo_ud.png` o `escudo_ud.jpg` o `escudo_ud.svg`
- `logo_labs.png` o `logo_labs.jpg` o `logo_labs.svg`
- `logo_ingenieria.png` o `logo_ingenieria.jpg` o `logo_ingenieria.svg`

Recomendaciones:

- Usa PNG con fondo transparente si es posible.
- Altura sugerida: 300 a 600 px.
- Evita imagenes muy pesadas; idealmente menos de 1 MB cada una.
- Si solo tienes una imagen, subela igual. El sistema usa placeholders para las que falten.
